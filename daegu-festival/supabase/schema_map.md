# 페이지 내용 ↔ 스키마 대조표

`web/index.html`의 내용이 어느 표에 들어가는지 정리한 표예요. 스키마는 `schema.sql`, 표는 모두 18개예요.

| 화면 | 페이지 내용 | 표 |
|---|---|---|
| 홈·행사개요 | 축제 이름, 기간, 장소, 운영 시간, 입장 안내 | `festivals` |
| 홈·행사개요 | 회차(제1회), 상세 장소, 하단 안내 문구 | `festivals` (추가 컬럼) |
| 홈 | 마스코트 소개 | `mascots` |
| 행사개요 | 3대 프로그램, 부대 프로그램 | `programs` |
| 행사개요 | 숙박 혜택, 스탬프투어 | `benefits` |
| 시간표 | 날짜별 무대·사랑방 일정 | `schedule_items` |
| 토론대회 | 대진표 | `debate_teams`, `debate_matches` |
| 토론대회 | 논제 | `debate_topics` |
| 토론대회 | 경기 일정·방식, 대구말 찬스, 예선, 논제 원칙 | `debate_rules` (추가) |
| 지도 | 구역 설명, 운영 시간 | `zones` |
| 지도 | 무대·화장실·쉼터 위치 표시 | `map_pois` |
| 능력고사 | 문제, 보기, 등급 | `quiz_questions`, `quiz_options`, `quiz_grades` |
| 능력고사 | 표준어 → 대구말 변환 | `dialect_rules` |
| 포장마차 | 메뉴, 대구말 주문 문구 | `menu_items` |
| 도우미 | 질문별 답변 | `faq_entries` |
| 도우미 | 인사말, 모를 때 답변, 추천 질문 | `assistant_messages` (추가) |

## 표로 만들지 않은 내용

| 내용 | 이유 |
|---|---|
| 체크인, 스탬프, 관객 투표, 숙박 인증 결과 | 방문자가 만드는 데이터라 쓰기 권한과 개인정보 설계가 먼저 필요해요 |
| 관객 투표 예시 숫자, 대기 번호 | 실제 값이 아닌 데모 값이에요 |
| 버튼 이름, 탭 이름 같은 화면 문구 | 페이지 디자인의 일부라 코드에 둬요 |
